# 桌面备忘录 · 技术文档

## 1. 概述

DesktopMemo 是一个 Windows 原生桌面备忘录，使用 Python 3.13 + PySide6（Qt 6）实现。界面为无边框（Frameless）圆角玻璃卡片窗口，全部业务状态持久化到本地 JSON 文件。项目以单文件源码 `client/main.py` 组织，便于阅读与二次开发。

### 1.1 设计目标

- 轻量、无服务端依赖，所有数据保存在本机。
- 自动化规则内建：完成归档、逾期提醒、历史与缓存周期清理。
- 外观可定制：背景色 / 背景图、深色模式、任务配色、矢量图标。
- 窗口可自由移动、缩放、锁定位置与置顶。

## 2. 技术选型与理由

| 关注点 | 选型 | 说明 |
| --- | --- | --- |
| GUI 框架 | PySide6 | Qt 官方 Python 绑定，原生窗口控件、SVG 渲染、样式表与事件系统完整。 |
| 界面样式 | Qt Style Sheet（QSS） | 提供浅色 / 深色两套样式表，玻璃面板、圆角、阴影通过 QFrame + QGraphicsDropShadowEffect 实现。 |
| 矢量图标 | QSvgRenderer | 加载本地 SVG，保留透明通道后用 `CompositionMode_SourceIn` 按当前主题色重着色。 |
| 持久化 | JSON 文件 | 任务、历史、设置写入 `data.json`；无数据库，降低部署复杂度。 |
| 打包 | PyInstaller onefile | 生成单文件 EXE；通过 `--manifest` 嵌入 PerMonitorV2 DPI 清单，`--add-data` 打入图标资源。 |

## 3. 目录与模块划分

```
client/
├── main.py          # 全部逻辑：数据模型、持久化、主窗口、任务卡片、定时规则、主题与缩放
├── memo.manifest    # Windows DPI 感知清单（PerMonitorV2）
├── logo.ico         # 应用图标（二进制）
└── icons/*.svg      # 功能按钮矢量图标
```

`main.py` 内部按职责划分为以下几部分：

1. **常量与持久化层**：路径、阈值、默认数据、`load_data` / `save_data`、缓存清理。
2. **图标渲染层**：SVG 路径解析、离屏渲染、主题着色与手绘兜底。
3. **背景容器 `BgWidget`**：自绘背景色 / 背景图，并按圆角路径裁切。
4. **任务卡片 `TaskCard`**：单条任务的展示、勾选、置顶、配色、备注编辑、删除。
5. **主窗口 `MainWindow`**：输入表单、列表编排、定时轮询、窗口拖拽与边缘缩放、主题切换、历史与设置对话框。

## 4. 数据模型

### 4.1 任务字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 唯一标识，时间戳 + 随机数生成。 |
| `title` | string | 任务标题。 |
| `note` | string | 备注，可为空。 |
| `color` | string | 任务配色（十六进制色值）。 |
| `pinned` | bool | 是否置顶。 |
| `done` | bool | 是否完成。 |
| `createdAt` | float | 创建时间戳（Unix 秒）。 |
| `completedAt` | float\|null | 完成时间戳。 |
| `lastActionAt` | float | 最近一次操作时间戳，用于空闲计时。 |
| `reminded` | bool | 是否已提醒过逾期，避免重复弹窗。 |
| `archivedAt` | float\|null | 归档时间戳。 |

### 4.2 顶层数据结构

```json
{
  "tasks":   [ /* 进行中与已勾选未归档的任务 */ ],
  "history": [ /* 已归档任务 */ ],
  "settings": {
    "dark": false,
    "bgType": "color",
    "bgColor": "#F1EEE9",
    "bgImage": "",
    "locked": false,
    "pos": null,
    "alwaysOnTop": false,
    "lastCleanup": null
  }
}
```

设置项含义：

- `dark`：深色模式开关。
- `bgType`：背景类型，`color` 为纯色，`image` 为图片。
- `bgColor` / `bgImage`：背景色值与本地图片路径。
- `locked`：锁定窗口位置（锁定后禁止拖拽移动）。
- `pos`：记忆的窗口位置 `[x, y]`。
- `alwaysOnTop`：窗口始终置顶。
- `lastCleanup`：上次历史 / 缓存清理时间戳，用于周日零点判断。

### 4.3 持久化位置

- 数据文件：`%APPDATA%\DesktopMemo\data.json`
- 缓存目录：`%APPDATA%\DesktopMemo\cache\`

读取时对缺失字段做 `setdefault` 补齐（`normalize_task`），兼容旧版本数据；写入使用 UTF-8、不转义中文。

## 5. 定时规则实现

主窗口启动一个 1 秒间隔的 `QTimer`，每轮触发 `tick()`。

### 5.1 完成归档（5 分钟空闲）

- 阈值 `DONE_IDLE = 300` 秒。
- 对已完成任务，以 `lastActionAt`（回退 `completedAt`、`createdAt`）为基准计算空闲时长。
- 达到阈值后写入 `archivedAt`，插入 `history` 头部，并从 `tasks` 移除。
- 编辑、置顶、改色、改备注等操作会刷新 `lastActionAt`，从而重置空闲计时。

### 5.2 逾期提醒（24 小时）

- 阈值 `OVERDUE = 86400` 秒。
- 未完成且未提醒过的任务，创建超过 24 小时即置 `reminded=True`、`pinned=True`，弹窗列出任务并自动置顶。
- 每个任务只提醒一次，避免重复打扰。

### 5.3 历史与缓存周期清理（每周日 00:00）

- `last_sunday_midnight(now)` 计算最近一个周日零点的时间戳。
- 若 `lastCleanup` 早于该时间点，则清空 `history`、静默清理缓存目录，并更新 `lastCleanup`。
- 清理在每次 tick 时判断，跨周后下一轮轮询即触发。

### 5.4 列表排序

任务按「置顶优先、同组按创建时间倒序」排序：

```python
sorted(tasks, key=lambda x: (not x["pinned"], -x["createdAt"]))
```

## 6. 窗口交互实现

### 6.1 无边框与拖拽

- 窗口标志：`Qt.FramelessWindowHint | Qt.Window`，并开启 `WA_TranslucentBackground`。
- 标题栏区域拖拽移动：在标题栏非控件位置按下左键，记录全局坐标与窗口左上角偏移，移动时 `move()` 跟随。
- 锁定（`locked=True`）后禁用拖拽与边缘缩放。

### 6.2 边缘缩放

- 命中带宽度 `RESIZE_M`，四边 + 四角通过 `_edges(pos)` 判定。
- 光标方向由 `_cursor_for(edges)` 映射：水平 / 垂直 / 两种对角光标。
- 按下时记录起始几何与起始全局坐标；移动时按受影响的边计算新的 `left/top/right/bottom`，并钳制到最小尺寸 `MIN_W × MIN_H`。
- 为防止子控件吞掉边缘鼠标事件，在中央部件上安装事件过滤器，将边缘区域的按下 / 移动 / 释放转发到主窗口统一处理。
- 释放后保存窗口位置。窗口矩形在显示时会被夹到屏幕可用几何内，避免移出屏幕。

### 6.3 最小尺寸

最小窗口默认 `320 × 380`；向内拖拽超出该尺寸时按对应边钳制，向外可自由放大。

## 7. 主题与背景

- 浅色 / 深色两套 QSS 存于主窗口，`apply_theme()` 根据 `settings["dark"]` 切换样式表与图标色。
- 背景由 `BgWidget.paintEvent` 自绘：
  - 纯色模式填充 `bgColor`；深色模式下浅色背景自动切换为深底色。
  - 图片模式按 `KeepAspectRatioByExpanding` 铺满并居中，叠加半透明蒙版（浅色 / 深色不同透明度）。
  - 背景以 `QPainterPath` 圆角裁切，半径 `RADIUS = 20`。
- 图标着色：`_render_svg()` 先用 QSvgRenderer 渲染到透明 QPixmap，再用 `SourceIn` 混合模式填充当前主题色。

## 8. 打包与 DPI

### 8.1 PyInstaller 参数要点

- `--onefile --windowed`：单文件、无控制台窗口。
- `--icon client/logo.ico`：嵌入 EXE 图标。
- `--add-data "client/icons;icons"`：将 SVG 图标目录打入 `_MEIPASS/icons`。
- `--manifest client/memo.manifest`：嵌入 PerMonitorV2 DPI 感知清单，避免高 DPI 下界面被虚拟化裁切。

### 8.2 资源路径解析

图标路径依次在「源码目录」与「`sys._MEIPASS` 打包临时目录」查找，开发态与打包态均可定位资源。

## 9. 关键数据流

```
用户输入 / 勾选 / 置顶 / 改色 / 备注
        │
        ▼
  TaskCard 发出 changed / deleteRequested 信号
        │
        ▼
 MainWindow 更新 data 结构 → save_data() 落盘 → rebuild_tasks() 重绘列表
        │
        ▼
 QTimer 每秒 tick()：归档 / 逾期提醒 / 周期清理 → 必要时落盘并刷新
```

## 10. 已知限制与扩展点

- **限制**：
  - 数据为单机本地 JSON，未做多端同步或云端备份。
  - 历史记录在周日零点整体清空，不提供永久归档。
  - 打包产物与二进制 Logo 不纳入 Git，克隆源码后需自行准备 `logo.ico`（缺失时回退默认图标）。
- **可扩展方向**：
  - 任务提醒通知（系统托盘 / 通知中心）。
  - 任务分类、标签与过滤。
  - 数据导出 / 导入（JSON 备份）。
  - 多语言与可配置主题色板。
  - 待办截止时间与重复规则。
